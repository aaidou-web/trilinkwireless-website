TriLink Wireless pre-launch website
Open index.html in a browser to preview. Upload index.html and CNAME to the root of a new GitHub repository. For a static pre-launch informational site, enable Pages under Settings > Pages, deploy from main / root, and configure the custom domain www.trilinkwireless.ca. Verify your domain in GitHub before changing DNS. In Wix DNS, set www CNAME to your GitHub account's <username>.github.io hostname and configure the apex domain using GitHub's current official DNS instructions. Preserve email records. Enable HTTPS after verification. See https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site . GitHub Pages is not intended for running an online business or ecommerce; migrate to suitable commercial hosting before activating transactions. No live account, contact form, or payment processing is included.
